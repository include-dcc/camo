# Common Access Model Ontology

Description: Organized terms in support of a shared data model.

More information can be found at http://obofoundry.org/ontology/camo

## Versions

### Stable release versions

The latest version of the ontology can always be found at:

http://purl.obolibrary.org/obo/camo.owl

(note this will not show up until the request has been approved by obofoundry.org)

### Editors' version

Editors of this ontology should use the edit version, [src/ontology/camo-edit.owl](src/ontology/camo-edit.owl)

## Contact

Please use this GitHub repository's [Issue tracker](https://github.com/include-dcc/camo/issues) to request new terms/classes or report errors or specific concerns related to the ontology.
